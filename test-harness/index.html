Vector search, in your browser

Real IndexedDB, deterministic synthetic vectors, exact cosine nearest neighbours. No model downloads or semantic text search. Everything stays in this browser.

100k vectors may take minutes and significant disk space. Data is disposable: each dataset gets its own database; deletion is requested when replaced or when you leave. The library cannot close its connection, so deletion may wait for the page to close. No existing application databases are touched.

What is being compared?


All: the unmodified library cursor scan versus an experimental paged getAll scan
with query norm computed once. Category 7: exact predicate-before-top-k versus an IndexedDB
metadata index over a separate copy with identical records. Timing includes IndexedDB reads and scoring,
not dataset creation. These alternatives are experiments, not new library APIs.


Filtering only after the global top 10 is not equivalent to finding the top 10 in a category;
the demo prints that negative control. Approximate search is not implemented.
