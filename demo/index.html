    What “offline” means here

    After loading, this open page needs no network to turn new questions into vectors or search. Turn off Wi-Fi or use your browser’s offline mode and try it. The connection label reports the browser’s connection hint, not a guarantee of internet access.

    Passages and their vectors stay in IndexedDB on this device. Model files use the browser’s cache; the running model and runtime are in memory. Reloading or reopening this page requires a network connection to load the app and runtime — there is no service worker. Browser storage can be cleared or evicted. Wikipedia source links also need the network.

    Queries never leave this page. All assets come from this GitHub Pages site: no CDN scripts, remote fonts, API keys or inference service.
